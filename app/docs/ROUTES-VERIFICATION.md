## Исправления по результатам проверки

- Нажатие линии варианта больше не ставит новую конечную точку.
- Отключены анимации Leaflet, вызывавшие `_leaflet_pos` при смене карты.
- Успешный GPS fix снимает прежнюю ошибку геолокации.
- Повтор тех же координат не оставляет пустой предпросмотр.
- Истёкший или уже использованный предпросмотр пересчитывается; неясный результат отправки сохраняет исходный запрос для безопасного повтора.
- На телефоне кнопка обновления отображается иконкой с доступным названием.
