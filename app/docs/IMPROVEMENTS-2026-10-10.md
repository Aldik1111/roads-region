# Улучшения и проверка — 10 октября 2026

Работа распределена между тремя GPT-6 Luna субагентами: карта/маршрут, очередь/хранение, сервер/администрирование. Ведущий агент объединил UI, проверил изменения и исправил найденные при повторном просмотре ошибки.

## Что добавлено

| Область | Результат |
|---|---|
| Карта | Загрузка, задержка, отсутствие сети, ошибка тайлов и повтор без сброса вида; запоминание центра/масштаба; настройка источника тайлов при сборке |
| Маршрут | Оценка наблюдаемого покрытия, оставшегося расстояния, длительности и дефектов выбранного осмотра; пропуски GPS не считаются пройденными |
| Назначения | Редактирование названия, примечания и инспектора; версия записи и блокировка переназначения во время осмотра; уведомление нового инспектора |
| Очередь | Ожидающие, отправляемые, отклонённые и подтверждённые операции; исправление однозначно отклонённого сообщения; оценка хранения и ручная очистка подтверждённых фото |
| Проверка ремонта | Срок проверки (по умолчанию 48 часов), изменение с причиной, просрочка, увеличение фото с масштабом и оригиналом |
| Контроль | Внутренние уведомления о назначениях, сдаче, доработке и просрочке; переход к карточке/маршруту; отчёт подрядчиков |
| Эксплуатация | Отключение демо-входа, создание личных пользователей через CLI, резервная копия/проверка/восстановление SQLite, конфигурация Docker/Caddy/PostgreSQL |

Отчёт показывает текущее состояние назначений, а среднее время — последний корректный интервал «начало работ → сдача» по закрытым обращениям с доступной историей. Уведомления обновляются в открытом кабинете; прочитанность и push не добавлены. GPS-покрытие является оценкой по полученным точкам, а не доказательством качества осмотра.

## Проверки

- `python -m pytest backend/test_api.py tools/test_admin_backup.py tools/test_init_deploy.py -q`: **47 passed, 1 skipped**. Пропущен тест создания символьной ссылки: Windows не разрешил её создание. Предупреждение Starlette/httpx о будущем изменении зависимости не влияет на результат.
- В API включены права ролей, версия маршрута, одновременное начало осмотра и переназначение через отдельные соединения файловой SQLite, пробельное название, срок проверки и точное время ремонта.
- `npm run test:gps`: **19 групп** прошли, включая задержку уведомления, восстановление, отзыв разрешения и защиту операций при устаревшей позиции.
- `npm run test:field-queue`: реальный IndexedDB, порядок и изоляция владельцев, потерянный ответ, исправление отказа с новым ключом, ошибки фото, безопасная очистка и конкуренция с записью — прошли.
- `field-work-browser.cjs`: потеря сети, перезагрузка, сохранение текста/оригинала фото, восстановление, очередь и завершение — прошли; после двух запросов создан ровно один тестовый дефект.
- `inspector-review-browser.cjs`: на **1440/390 px** прошли доработка/приёмка, контрольное фото, обязательные пункты, GPS, увеличение фото до 3× и закрытие просмотра; ошибок страницы и горизонтальной прокрутки нет.
- `gps-grace-browser.cjs`: на **1440/390 px** прошёл сценарий краткой потери и восстановления GPS, без ошибочной отправки фото.
- `team-workflow-browser.cjs`: на **1440/390 px** проверены уведомления, отчёт, переход к маршруту, переназначение и изменение срока проверки из карточки с причиной и версией; отдельно — пустые поля личного входа и отсутствие демо-подстановки.
- Геометрия маршрута: **9 тестов** прошли, включая обратное движение, движение на 90 км/ч, невозможный скачок, пропущенное начало и повторный проезд. Браузерные проверки загрузки/ошибки/повтора и смены маршрута прошли; перехвачено 48 запросов видимых тайлов, публичный сервер не нагружался. Детали — [MAP-IMPROVEMENTS.md](MAP-IMPROVEMENTS.md).
- `npm run build`: проходит. Vite сообщает о крупном основном JS-файле; разделение загрузки остаётся возможной оптимизацией.
- `docker compose -f compose.production.yaml config --quiet` с тестовыми переменными: проходит. Docker Engine недоступен, поэтому сборка/запуск контейнеров и PostgreSQL **не проверены**.
- Резервная копия рабочей базы и **16 фотографий** проверена по хэшам и восстановлена отдельно. Исходные данные не заменялись.
- После перезапуска `/api/health` на localhost и локальном HTTPS возвращает `ok: true`, `database: sqlite`, `demo: true`.

Браузерные API-записи перехватывались, тесты не создавали пользовательские обращения. GPS эмулировался; настоящий Android и поездка по трассе ещё не проверены.

## Что ещё требует отдельного этапа

Публичный сервер/домен, реальные учётные записи, перенос SQLite в PostgreSQL и регулярные production-копии не запущены. Полная офлайн-подложка требует подходящего источника карт; непрерывный GPS при заблокированном экране — отдельного Android-решения. Эти функции не выдаются за реализованные возможности браузера.
