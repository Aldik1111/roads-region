# Assigned routes — approved design and implementation contract

User approved: dispatcher places exactly two endpoints. Request reasonable road alternatives; auto-select a sole returned route. With multiple alternatives highlight divergence points and require an explicit choice. Save only that chosen geometry and assign an inspector. Inspector sees own routes, chooses one, starts inspection; at most one active inspection per inspector. Dispatcher sees planned geometry, actual GPS and defects afterwards. Preserve data and existing styling.

Use existing Section shape as backward-compatible assigned route representation: route IDs remain `section_id` in inspections/defects. Add a persistent route table, retain legacy r-01 and its existing observations. No editing/deletion of published geometry in this scope. Route status is computed from latest inspection; completed routes remain available for history and explicit repeat inspection.

## API (all /api)
POST /routes/preview {start:RoutePoint,end:RoutePoint} -> RoutePreview, dispatcher only. Exactly two distinct valid points, automotive roads; timeout/unreachable/no route -> descriptive 422/503, never fabricate straight lines. Server persists preview options owned by dispatcher with expiry (60min). OSRM configurable URL via ROUTING_BASE_URL, default https://router.project-osrm.org. Fetch route/v1/driving/lng,lat;lng,lat?alternatives=true&geometries=geojson&overview=full&steps=true. Do not claim all paths found; UI 'Найден один вариант' or 'Выберите один из найденных вариантов'. Road snapping can shift endpoints; return actual snapped endpoints. Reject unreasonably distant snaps (over 500m). API shape validated before DB write. Candidate IDs stable within preview.
POST /routes {name:string,notes:string,inspector_id:string,preview_id:string,option_id:string} -> Section. Dispatcher only; server validates owner, expiry, option membership and inspector role. Geometry copied from persisted preview, not accepted from client. Repeat SAME payload for preview returns same route, changed payload returns409. Missing option_id when multiple ->422. Frontend always sends selected id even one. Submitted preview can only produce one published route.
GET /routes -> Section[] with same visibility as bootstrap.
GET /routes/{id}/results -> {route:Section,inspections:Inspection[],defects:Defect[]} dispatcher or assigned inspector only. Persisted track and existing history; no made-up coverage percentage.
Existing start inspection validates assignment; same active route returns existing record, different route when active ->409 ACTIVE_INSPECTION. Existing create defect validates route exists and belongs to inspector. Existing global review workflow retained. Optional Defect section_name/section_code supplied by backend for operations cards. Existing /inspections/{id} ownership remains inspector-only; dispatcher reads results endpoint instead.
