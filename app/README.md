# Дороги области — рабочий MVP

Локальное приложение: **http://localhost:8000**. Исходный дизайн сохранён без изменений в `design/reference.html`. Интерфейс использует его тёплый светлый фон, тёмно-зелёную навигацию, бирюзовые действия и пастельные статусы.

## Что работает

- Инспектор: участки, осмотры, запись GPS в открытой вкладке, ручная точка, фото и описание дефекта, уточнение, приёмка и доработка, повторный дефект после закрытия.
- Диспетчер: список, карта, поиск и статусы, назначение, смена исполнителя и срока с причиной, запрос сведений, сравнение и связывание дубликатов, отмена.
- Подрядчик: только свои назначения, принятие и начало работ, фотоотчёт, повторная сдача после доработки.
- Оригиналы фотографий, история действий, отдельные попытки ремонта, проверка ролей на сервере, контроль версии записи и повторных отправок.
- ПК: несколько рабочих колонок; планшет: компактная компоновка; телефон: переключаемые панели и нижняя навигация инспектора. Снимки экранов находятся в `docs/screenshots`, галерея — `docs/GALLERY.html`.

## Вход

На странице входа выберите роль: логин и пароль подставляются автоматически.

| Роль | Логин |
|---|---|
| Инспектор | inspector@roads.local |
| Диспетчер | dispatcher@roads.local |
| Подрядчик | contractor@roads.local |
| Другой подрядчик для проверки прав | contractor2@roads.local |

Общий демонстрационный пароль: `RoadsDemo2026!`. Учебные фото — искусственные иллюстрации, а геометрия и заявки — демонстрационные данные.

## Запуск в этой папке

```powershell
.\start-local.ps1
# После изменения frontend:
.\stop-local.ps1
.\start-local.ps1 -Build
# Остановка:
.\stop-local.ps1
```

Сервер запускается скрытым процессом, логи находятся в `logs/`. SQLite хранится в `backend/roads.db`, загруженные оригиналы — в `backend/uploads/`. Эти локальные данные исключены из Git. Для резервной копии остановите сервер и скопируйте оба места вместе.

На новом компьютере нужны Python 3.12+ и Node.js 22+:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
Set-Location frontend
npm ci
npm run build
Set-Location ..
.\start-local.ps1
```

Разработка с обновлением интерфейса: сервер на порту 8000 и `npm run dev` из `frontend` на 5173. Vite проксирует `/api` на сервер.

## Стек и PostgreSQL

React 19, TypeScript, Vite, Leaflet, FastAPI, SQLAlchemy. В текущем запуске используется **SQLite**: движок Docker на компьютере недоступен. PostgreSQL поддерживается кодом, но в этой сессии не запускался и не тестировался.

Для PostgreSQL: скопируйте `.env.example` в `.env`, задайте пароль, запустите `docker compose up -d`. Перед запуском сервера установите `$env:DATABASE_URL='postgresql+psycopg://roads:ВАШ_ПАРОЛЬ@localhost:5432/roads'`. Пароль в URL должен быть URL-кодирован. Существующие SQLite-данные автоматически не переносятся; новая база получит демо-записи.

## Проверки и границы MVP

```powershell
.\.venv\Scripts\python.exe -m pytest backend/test_api.py -q
Set-Location frontend
npm run build
```

Подробные результаты — `docs/VERIFICATION.md`. GPS проверен эмуляцией браузера; поездка с реальным телефоном не проводилась. На localhost геолокация доступна, для доступа с телефона по сети нужен HTTPS. Сервер по умолчанию слушает только этот компьютер.

GPS записывается при видимой вкладке. При скрытии вкладки/блокировке телефона запись может прерываться; интервалы более минуты отмечаются на карте. Полноценной автономной синхронизации нет: неотправленные точки находятся в памяти вкладки, выход с такими точками вызывает предупреждение. Карта OpenStreetMap и шрифт требуют интернет; при недоступной подложке геометрия и точки остаются.

Это локальный MVP: перед публикацией нужны настройки production-доступа, HTTPS, резервное копирование и миграции схемы. Регистрация пользователей, push-уведомления и фоновая GPS-запись в этот этап не входят.
